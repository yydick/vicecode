## 1. 环境要求与安装

- **PHP >= 8.3**
- 扩展：**swoole**（推荐，提供协程底座）；未安装时自动回退到纯阻塞读模式
- 依赖：`php-tui/php-tui ^0.2`、`scrivo/highlight.php ^9.18`

```bash
composer install
```

> **必须在真实终端（pty）里运行。** 管道 / 重定向下 raw mode 与尺寸感知不可用，应用会在启动时直接报错退出而不是留下一个坏掉的终端。

## 2. 启动

```bash
php bin/vicecode.php                      # 启动（默认走 Swoole 协程底座）
php bin/vicecode.php path/to/file         # 启动并直接打开文件（可跟多个）
php bin/vicecode.php .                    # 打开目录作为项目根
TUI_USE_SWOOLE=0 php bin/vicecode.php     # 强制回退到纯 php-tui/term 阻塞读模式
APP_LOCALE=en php bin/vicecode.php        # 英文界面（默认 zh_CN）
VICECODE_CONFIG=/tmp/vc.json php bin/vicecode.php   # 换一份配置文件（测试隔离常用）
```

## 3. 界面与布局

```
┌───────────┬────────────────────────────┬──────────────┐
│ Sidebar   │  Editor                    │ Terminal     │
│ Explorer  │  (语法高亮/多标签/...)      │ (命令/交互)   │
│ GIT       │                            │              │
│ Search    │                            │              │
├───────────┴────────────────────────────┴──────────────┤
│ AI 对话流                                  │ AI 输入框  │
├───────────────────────────────────────────┴────────────┤
│ StatusBar                                                  │
└───────────────────────────────────────────────────────────┘
```

- **六个可聚焦面板**：侧栏 / 编辑器 / 终端 / AI 对话流 / AI 输入框（状态栏不可聚焦）。
- **侧栏四个 tab**：资源管理器 / GIT / 搜索 / 🧩 扩展。点击 tab 行切换。
- **顶栏菜单栏**：`F10` 打开（文件 / 视图 / 终端 / 帮助 / AI / 插件）。
- **命令面板**：`F1`（或菜单「视图 → 命令面板」）列出全部命令，模糊过滤后回车执行。
- **分隔条**：用鼠标拖拽调整布局（仅当前会话有效，不落盘）。
- **状态栏**：随宽度自动裁剪（低价值段先被丢）。常见段：瞬时消息、`文件=`（含未保存 `*` 与 `N 个光标`）、`模式=`、`Provider=`、`策略=`、`分支=`、`焦点=`、`目录=`、`退出` 提示。
- **状态栏可点**：点 `语言=` 段会在状态栏上方弹出语言列表（`↑`/`↓` 选、`Enter` 或单击应用、`Esc` 或点别处关闭；当前语言前标 `●`）。菜单「视图 → 语言」打开的是同一个列表，主题同理（`Ctrl+T` 仍是快速循环）。没有列表的段（如 `文件=`）点了不会有反应。

## 5. 编辑器

### 打开与保存

- 在资源管理器里单击文件、或按 `Enter`，即在编辑器打开；`Ctrl+Tab` 在已打开文件间切换。
- `Ctrl+S` 保存，`Ctrl+W` 关闭当前文件。有未保存改动时状态栏文件名后带 `*`。
- **超过 5 MB 的文件以只读方式打开**并在编辑器顶部给出提示（避免整文件读入把内存顶爆）。
- 在编辑器里保存 `~/.vicerc` / `~/.vicecode.providers.php` 会**立即热生效**对应配置。

### 编辑按键

| 键 | 作用 |
| --- | --- |
| `↑ ↓ ← →` | 移动光标（行首行尾会跨行） |
| `Home` / `End` | 行首 / 行尾 |
| `PageUp` / `PageDown` | 翻页 |
| `Enter` | 换行 |
| `Backspace` / `Delete` | 删除前一个 / 后一个字符 |
| `Tab` / `Shift+Tab` | 缩进 4 空格 / 反向缩进 |
| `Ctrl+V` / `Shift+Ins` | 粘贴 |

### 符号自动配对

默认开启，配对集可在配置里改（见 [§11 配置](#11-配置)）：

```json
{ "editor": { "autoPairs": ["()", "[]", "{}", "\"\"", "''"] } }
```

行为：

- **打左补右**：输入 `(` 自动补 `)`，光标夹在中间。
- **跳过已有右符号**：光标右侧已经是同一个右符号时按右符号，只跳过、不重复插入（打完 `()` 再打 `)` 不会变成 `())`）。
- **空对退格成对删**：光标夹在空对中间时退格一次删两个；对子里已有内容则只删一个字符。
- **选中后包裹**：选中一段文本再打左符号，会把它包起来（跨行选区也支持）。
- **引号不跟在词后配对**：紧跟在字母 / 数字 / 下划线之后打引号不自动配对（`don't` / `it's` 不会被补成 `don''t`）。
- **缺省刻意不含 `<>`**：PHP 里 `<` 是运算符，`if ($a < $b)` 被补成 `<>` 只会添乱。想要就在 `autoPairs` 里自己加 `"<>"`。
- **显式写 `[]` 即关闭**（与「没写」区分开，否则没法真的关掉）；列表里的脏条目（非字符串 / 长度不等于 2 / 重复）会被逐条丢掉，不会因为一条坏数据让整个功能失效。

### 多光标（多行同时编辑）

- **加光标**：`Alt+↑` / `Alt+↓` 在上 / 下一行加一个（列对齐），或 `Alt+点击` 在点击处加一个。
- **每行最多一个光标**：`Alt+点击` 落在已有光标的行不会再新增。
- **一次输入，全部生效**：打字、`Backspace`、`Delete`、`Enter`、`Tab` / `Shift+Tab` 缩进会**同时作用于所有光标**。
- **取消**：`Esc` 收起多余光标回到单光标；此时 `Esc` **不会**退出程序（再按一次才走全局退出流程）。
- **状态栏**：`文件=` 段显示「`N 个光标`」。
- **不参与的能力**（只作用于主光标）：**自动配对**与**粘贴**。自动配对之所以不参与，是因为不同位置「该不该配对」可能不同，一次输入产生不同结果无法预期。
- `Alt+点击` **只加光标、不产生选区**（不按 `Alt` 拖拽才是普通的拖选复制）。

### 选择与复制

- 鼠标在编辑器内容区按住拖拽即可选中，松开即复制到系统剪贴板（终端支持 OSC52 时走 OSC52，否则降级到应用内剪贴板）。
- 终端面板的输出同样可以拖选复制。

### AI 快捷动作

- `Ctrl+E`：把当前文件（或选中内容）发给 AI 解释，起一个全新对话直接发送。

## 6. 终端面板

终端面板有两种模式，`F2` 在两者之间切换。

### 6.1 命令运行器模式（默认）

像普通命令面板一样跑命令：

- 在底部输入行键入命令，`Enter` 执行；输出实时流式显示。
- `↑` / `↓` 浏览命令历史；`Home` / `End` 跳到行首 / 行尾。
- `Ctrl+C` 中断正在运行的命令；`Ctrl+L` 清空输出。
- `PageUp` / `PageDown` 回看历史输出（自动退出「贴底跟随」）。

### 6.2 交互式 PTY 模式

按 `F2` 分配一个**真实 PTY** 并启动交互式 shell（bash），所有按键被直接转发给 shell —— 因此可以跑 `vim`、`top`、`less`、`ssh` 等任何依赖完整终端的程序。内置轻量 VT100/ANSI 仿真器负责解析光标定位、着色、擦除、滚动与交替屏。

- **进入捕获**：终端面板聚焦时按 `F2`。
- **退出捕获**（shell 仍在后台跑）：捕获态下按 `Esc` 或再次 `F2`。退出后焦点回到应用导航，可用 `PageUp` / `PageDown`、方向键浏览回退内容。
- **重新进入**：shell 还没退时再按 `F2` 即可。
- **结束 shell 回到运行器**：捕获态发送 `Ctrl+D` 或 `exit`，shell 结束后自动退回命令运行器模式。
- 终端标题显示当前状态（`交互终端` / `捕获中`）。

> 窗口尺寸随面板大小自动通过 `stty` 同步给 shell；宽字符（CJK）按 2 列占位渲染。

### 6.3 会话持久化（默认关闭）

默认退出 ViceCode 时交互式 shell 会随进程一起死掉（PTY 是 OS 进程，退出即被回收）。开启后，退出时会把终端快照——滚动历史 + 当前**主屏纯文本** + 启动工作目录——落盘，下次启动自动起一个新 shell 并灌回去，让会话看起来「续上了」。

- **开启**：在配置文件里加 `"persistSession": true`。
- 快照写到 `~/.vicecode_session`（或 `dirname(VICECODE_CONFIG)/.vicecode_session`），权限 `0600`；恢复成功后即被消费（删除），不会二次恢复。
- **隐私提示**：滚动历史可能含在提示符后键入的密码 / 令牌。文件为 `0600`，但仍属敏感，只在可信机器上开启。

**局限性（v1，设计使然）：**

- 只持久化**主屏**；`vim` / `top` / `less` / `ssh` 等全屏程序跑在交替屏，刻意排除——它们的冻结 UI 重启后会变成垃圾。
- **不含颜色**，仅纯文本。
- 只恢复**启动**工作目录；在 shell 内 `cd` 过的目录不恢复。
- PTY 进程本身无法序列化；恢复的是一个灌入了快照文本的新 shell，其新提示符接在快照之后。

## 7. 资源管理器

侧栏第一个 tab，展示项目目录树。

| 操作 | 效果 |
| --- | --- |
| `↑` / `↓` | 移动选中 |
| `→` | 目录未展开 → 展开；已展开 → 选中第一个子项；文件上无效 |
| `←` | 目录已展开 → 折叠；否则选中父节点 |
| `Enter` | 展开 / 折叠目录，或打开文件 |
| 单击文件 | 打开 |
| 单击行首三角 | 展开 / 折叠 |
| 双击目录 | 展开 / 折叠 |

> 目录树是**懒展开**的：只扫描当前展开层，不会一次性把整棵树读进内存（对超大目录友好）。

## 8. GIT 面板

侧栏第二个 tab。列表按「变更 / 日志」两个子视图切换（状态数是左侧标题，右侧 `+ -` 或 `⟳` 图标可点击）。

| 键 / 操作 | 作用 |
| --- | --- |
| 直接键入 | 输入提交信息（写在面板底部的输入框里） |
| `Backspace` | 删除提交信息末字符 |
| `Enter` | 提交（信息为空会拒绝并提示） |
| `↑` / `↓` | 在变更 / 日志列表间移动选中 |
| `+` 或 `=` | 暂存选中文件 |
| `-` | 取消暂存选中文件 |
| `Esc` | 关闭打开的下拉菜单 |
| 点击图标 | 暂存 / 取消暂存 / 丢弃改动 / 查看 diff |
| 点击分支名 `⎇ … ▾` | 打开分支下拉：`↑` / `↓` 选择、`Enter` 切换、`Esc` 取消 |
| 点击 `Commit ▾` | 展开提交动作下拉 |

`Commit ▾` 下拉的四个动作：

- **提交** —— 只提交已暂存的改动
- **提交变更** —— 先 `git add -A` 再提交
- **提交和推送** —— 提交后 `push`
- **提交和同步** —— 提交后同步（pull + push）

> GIT 命令走原生阻塞 `exec`（`git status` 很快，可接受）；搜索结果不做阻塞执行，见下一节。

## 9. 搜索面板

侧栏第三个 tab，搜索**文件内容**（不是文件名）。

- 键入关键词 → `Enter` 开始搜索（随时可继续输入修改关键词）。
- 底层是 `grep -rnI -F`：固定字符串匹配、递归、跳过二进制文件。
- **默认排除** `.git`、`vendor`、`node_modules`、`dist`、`build`、`.idea`、`.vscode`、`.svn`、`.cache`、`__pycache__`、`target`。
- **结果上限 2000 条**，超出会截断并提示（缩小范围再搜）。
- 结果按文件分组：`↑` / `↓` 移动选中，`Enter` 在折叠组上展开 / 折叠、在命中行上打开对应文件并跳到该行。
- 搜索期间界面仍可操作（搜索跑在子进程里，不阻塞事件循环）；再次 `Enter` 会取消上一次搜索并重新开始。

## 10. AI 助手

右侧 AI 面板接入工作台：**OpenAI / DeepSeek 兼容端点**，以及 **Claude 原生（Anthropic Messages API）**。配置在 `config/providers.php`（或用户级 `~/.vicecode.providers.php`），key 走环境变量；经 `curl` 子进程流式输出，UI 全程不阻塞。

### 10.1 协议：两种

每个 provider 写 `protocol`：

- `'openai'`（**默认**，不写即此）—— 任何 `/chat/completions` 端点：OpenAI、DeepSeek、OpenRouter、Kimi、千问、GLM、Ollama、vLLM、自建网关等。
- `'anthropic'` —— Claude 原生：`POST /v1/messages`，`x-api-key` + `anthropic-version` 头，`system` 走顶层参数，`max_tokens` 必填（provider 级 `max_tokens` 可配，默认 4096）。

两种协议下**工具调用（Agent loop）都完整可用**（`tool_use` / `tool_result` 往返）。内部消息形状（OpenAI 语义）不变——协议转换只在 provider 出口做一次，存档 / 渲染 / 复制三处零改动。

内置已带一条 `anthropic`（模型 `claude-opus-4-8` / `claude-sonnet-4-6` / `claude-haiku-4-5-20251001`，key 取 `ANTHROPIC_API_KEY`）。

### 10.2 模型能力声明

在 provider 配置里按模型声明能力：`tools` / `reasoning` / `vision` / `audio`（也接受自定义名字）；provider 级可给默认值；**不写则默认支持 `tools`**（老配置零迁移）。

当前**只有 `tools` 影响行为**：只有声明了它的模型，请求里才会带工具定义——纯推理模型（`deepseek-reasoner` 已预声明为 `['reasoning']`）因此不会因为带工具被服务商拒掉整轮请求。

当前模型的能力显示在 AI 面板空态提示里；缺少 `tools` 时状态栏 AI 段会带「无工具」标记。

### 10.3 用户级模型配置（免改仓库）

菜单「AI → 编辑模型配置…」在**内置编辑器**里打开 `~/.vicecode.providers.php`（不存在时先生成带注释的模板）。格式与 `config/providers.php` 一致，**按 id 逐字段覆盖、新 id 追加**（`models` 整体覆盖）。所以「只想把 `openai` 指向自建网关」只写一个 id + 要改的字段即可。`Ctrl+S` 保存即热重载，当前 provider / model 会保留；文件语法写错时沿用上一份可用配置并在状态栏提示。

### 10.4 模型策略（多档位切换）

同一份配置里的 `@strategies` 段把「这次要干什么」映射到具体模型（如 `plan` → 推理模型、`grind` → 便宜模型）。

- AI 面板按 `Ctrl+R` 循环切换，或从菜单 / 命令面板直接选一条；状态栏常显当前档位。
- 策略可写 `requires` 声明能力要求（如 `['tools']`）——**切换时若目标模型不具备该能力会拒绝并提示**，避免「降级到便宜模型」把 Agent 工具**静默**废掉。
- 写错 provider / model 同样拒绝（不会静默回退到别的模型）。
- 手动切 provider / 模型会自动脱离策略，状态栏不会显示错的档位。

### 10.5 按任务类型自动选档

策略可声明 `kinds`（如 `['unittest', 'refactor']`），请求带上该类型时自动用这一档。类型只有两个来源、都不靠猜：

- **快捷动作**（解释 / 注释 / 重构 / 单元测试）；
- 输入框的**指令前缀**，如 `/plan 帮我把这块重构一下`（前缀不发给模型；未知类型会拒绝发送并列出已知类型；字面量斜杠写 `//`）。

**人工优先**：手动选档（`Ctrl+R` / 菜单 / 手切 provider）会钉住、自动暂停；`Ctrl+R` 的循环里有一档「自动」可切回。状态栏用 `策略=计划·自动` / `策略=计划` 明确标出「现在听谁的」，钉住时收到带类型的请求还会明说「自动选档未生效」。

### 10.6 代码上下文：`@路径`

输入框里用 `@项目内路径` 引用文件——发送前自动展开成带语法高亮的围栏代码块。

- 路径经项目根校验：`../`、绝对路径、出根 symlink、二进制一律拒绝。
- 单文件上限 `ai.attachMaxBytes`（默认 64 KB），超限截断并标注。
- 菜单「AI → 附加编辑器选区 / 附加当前文件」同样注入上下文。

### 10.7 Tab 补全与缩进

- 输入 `@` 即弹出**项目内路径候选**（目录带尾斜杠，可用前缀过滤）。
- `Tab` 接受、`Shift+Tab` 选上一个、`Esc` 关掉候选（不退出其它东西）。
- **没有候选时**，`Tab` 在 AI 输入框与编辑器里插 4 空格缩进、`Shift+Tab` 反向缩进。
- **单行输入**（搜索框 / 提交框）与其它面板仍是 `Tab` 切焦点（反向用 `Shift+Tab`）——单行插缩进没有意义。
- 插件也能通过 `completions()` 提供候选（同一个按键、同一个浮层），这是将来接 AI 自动补全的落点。

### 10.8 只读工具（Agent loop）

模型可在项目内调用 `list_files` / `read_file`。调用在**本地同步执行**，循环持续到模型作答或达到 `ai.maxSteps`（默认 8）轮。

- 消息流里可见调用行（`→ name(args)`）与单行结果摘要（`⚙ name(path) ✓`）——文件内容**不会**倾倒进对话。
- 点击复制 tool 行得到的是摘要。
- 设 `ai.toolAutoRun: false` 改为逐次确认（`y` 放行 / `n` 拒绝，`Esc` 取消）。

### 10.9 上下文压缩

估算 token 超过 `ai.compactThreshold`（默认 24000）时，自动把旧历史压缩成摘要（保留最近 `ai.compactKeepRecent` 默认 6 条）再发真实请求。

- 压缩绝不拆散 tool_call / 结果对；失败则降级为不压缩、历史一条不丢。
- 菜单「AI → 立即压缩对话历史」可手动触发。

### 10.10 对话持久化与渲染

- **持久化**（默认开启）：每轮收尾落盘到 `~/.vicecode_ai`（`0600`），重启自动恢复对话与 provider / model；`Ctrl+L` 清空对话并同步清档。`ai.persist: false` 关闭。
- **Markdown 渲染**：定稿消息渲染标题、列表、引用、行内代码 / 链接 / 粗斜体与围栏代码块（scrivo 高亮）；流式中的消息先按纯文本显示，定稿后切换。**单换行保留为独立行**。
- 点击一条定稿消息即可复制其整段内容。

### 10.11 AI 面板按键

| 键 | 作用 |
| --- | --- |
| 可打印字符 | 输入消息 |
| `@` | 引用项目内文件（发送前展开） |
| `Tab` / `Shift+Tab` | 有候选时接受补全 / 选上一个；无候选时插 4 空格缩进 |
| `Enter` | 发送 |
| `Ctrl+P` | 切换 Provider |
| `Ctrl+N` | 切换模型 |
| `Ctrl+R` | 切换模型策略 |
| `Ctrl+L` | 清空对话 |
| `Ctrl+V` / `Shift+Ins` | 粘贴 |
| `↑` / `↓` | 调取历史提问 |
| `PageUp` / `PageDown` | 滚动消息流 |
| `Esc` | 停止生成 |

### 10.12 AI 快捷动作

菜单「AI → 解释这段代码 / 加注释 / 重构建议 / 编写单元测试」（也在 `F1` 命令面板里）；编辑器内 `Ctrl+E` 把当前文件（或选区）发给 AI 解释，起全新对话直接发送。

## 11. 配置

### 11.1 `~/.vicerc`

配置落盘到 `~/.vicerc`（JSON），退出时自动保存。保存时 ViceCode 会**合并**已有配置，手改的 key（如 `persistSession`）不会被覆盖丢失。

```json
{
  "persistSession": false,
  "ai": {
    "persist": true,
    "toolAutoRun": true,
    "maxSteps": 8,
    "compactThreshold": 24000,
    "compactKeepRecent": 6,
    "attachMaxBytes": 65536
  },
  "editor": {
    "autoPairs": ["()", "[]", "{}", "\"\"", "''"]
  }
}
```

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `persistSession` | `false` | 交互终端会话持久化（见 §6.3） |
| `ai.persist` | `true` | 对话持久化到 `~/.vicecode_ai` |
| `ai.toolAutoRun` | `true` | 工具调用自动放行；`false` 改为逐次确认 |
| `ai.maxSteps` | `8` | Agent loop 最大轮数 |
| `ai.compactThreshold` | `24000` | 估算 token 超过此值触发压缩 |
| `ai.compactKeepRecent` | `6` | 压缩时保留的最近消息条数 |
| `ai.attachMaxBytes` | `65536` | 单个 `@文件` 附加上限（字节） |
| `editor.autoPairs` | `["()","[]","{}","\"\"","''"]` | 符号自动配对集；显式 `[]` 关闭（见 §5） |

布局 / 主题 / 语言也在这个文件里。

### 11.2 模型配置

- 仓库内置：`config/providers.php`
- 用户级覆盖：`~/.vicecode.providers.php`（菜单「AI → 编辑模型配置…」打开，按 id 逐字段覆盖 / 追加，保存即热重载）
- 详见 [§10.1](#101-协议两种) ~ [§10.5](#105-按任务类型自动选档)。

### 11.3 插件配置

`~/.vicecode.plugins.json`（与 `~/.vicerc` 分离）—— 见 [§12](#12-插件系统)。

### 11.4 环境变量

| 变量 | 作用 |
| --- | --- |
| `VICECODE_CONFIG` | 覆盖配置文件路径（测试隔离用，避免污染家目录） |
| `APP_LOCALE` | 界面语言，默认 `zh_CN`，可选 `en`；缺失的 key 回退英文 |
| `TUI_USE_SWOOLE` | `0` 强制回退到纯阻塞读模式 |

各 provider 的 API key 通过其配置里声明的环境变量读取（如 `OPENAI_API_KEY` / `DEEPSEEK_API_KEY` / `ANTHROPIC_API_KEY`）。

## 12. 插件系统

插件在**运行时**动态加载：应用启动时扫描 `plugins/<id>/plugin.json`，读取入口文件后用 `require` 加载并实例化插件类（不走 composer autoload）。单个插件加载失败会被跳过，不影响整体启动。

**内置示例：`clock` 插件**（`plugins/clock/`）——在状态栏右侧显示当前时间，并每秒自动刷新。

### 管理插件

- 侧栏 🧩 **扩展** tab：`↑` / `↓` 选中，`Space` 切换启用 / 禁用（立即热生效），`Enter` 用内置编辑器打开配置文件。
- 被禁用的插件仍列在列表里（标注 `[已禁用]`），否则禁用以后就再也找不到、没法恢复。
- 菜单「文件 → 已安装插件」同样可打开配置。

### 编写插件

1. 在 `plugins/<id>/` 下创建 `plugin.json`：

   ```json
   { "id": "myplugin", "entry": "MyPlugin.php", "class": "MyPlugin" }
   ```

2. 实现 `App\Plugin\PluginInterface`。核心能力（均为可选，用 `method_exists` 探测）：
   - `id()`：稳定唯一标识；
   - `statusSegments(App $app)`：向底部状态栏注入自定义段；
   - `tickInterval()`：需要周期刷新时返回秒数；
   - `panels()`：提供自定义面板（浮层内 tab 切换）；
   - `completions(context, text, cursor, prefix)`：为输入框提供补全候选（与内建 `@文件` 补全共用同一按键与浮层）。

3. 放置入口文件即生效，**无需重新编译**。

插件文件写普通 PHP 即可，不受 AOT 编码规范约束（那些只管编入二进制的核心源码，见 [docs/AOT_INCOMPATIBILITY_REPORT.md](AOT_INCOMPATIBILITY_REPORT.md)）。

完整插件开发文档（编写 / 加载机制 / 字段取值 / 测试）见 [docs/plugins.md](plugins.md)。

## 13. 故障排查

### 终端被留成乱码（鼠标乱码 / 无回显 / `-bash: 35: command not found`）

典型成因是进程**非正常终止**，收尾没跑完，终端还停在 raw mode + 备用屏 + 鼠标上报开启的状态。

收尾现在覆盖这些退出路径：

| 死法 | 终端还原 | 日志 |
| --- | --- | --- |
| 正常退出 / 可捕获异常 | 是 | 不写（本来就没出事） |
| PHP 致命错误（含内存耗尽） | 是 | 是，写进 `.vicecode_fatal.log` |
| 被信号终止（`SIGTERM` / `SIGHUP` / `SIGINT`） | 是 | 是，并记明是哪个信号 |
| **`SIGKILL` / 段错误** | **否** —— 进程没有任何机会执行代码 | 间接（见下） |

日志在**配置目录下**：

```bash
cat ~/.vicecode_fatal.log       # 只有非正常退出才会有内容
```

同目录还有一个「本次会话还活着」的标记 `.vicecode_alive`：启动时写、**只有正常退出**才删。所以如果上次是被 `SIGKILL` 或段错误这类**无法拦截**的方式弄死的，下次启动会往日志里写一条 WARN（带上上次的启动时间与 pid），并在进入界面前于终端上打印一句提示 —— 这是唯一能发现那类死亡的办法。同时开着两个 ViceCode 不会误报（标记里记了 pid，那个进程还活着就不算残留）。

**如果终端还是乱的**，手动救回来：

```bash
printf '\e[?1000l\e[?1006l\e[?1015l\e[?1002l\e[?1003l\e[?1049l\e[?25h'; stty sane
```

（`reset` 也行，但会清屏。）

### 启动就报错退出

- 确认在**真实终端**里运行，不是管道 / 重定向。
- `php -m` 看 swoole 是否装上；没有也能跑（自动回退阻塞模式），但会提示。

### 大文件 / 超大目录

- 编辑器对 > 5 MB 文件只读打开（有提示）。
- 目录树懒展开，读盘只发生在展开某一层时。
- 搜索默认排除 `vendor` 等目录，结果上限 2000 条。

### 切换语言后界面出现 key 字面量

说明语言包漏了 key。`php tests/i18n_parity.php` 会直接指出中英两包不一致的地方。
